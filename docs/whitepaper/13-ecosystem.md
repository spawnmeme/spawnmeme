# 13. Public resources and participation

## A public information layer

SPAWN's public repository provides platform guides, a roadmap overview, creator preparation material, community links and media resources. It supports a more inspectable, versioned record of how the platform is described.

The repository does not contain the production application or its private deployment configuration. Publishing documentation on GitHub does not make the entire platform open source or grant unrestricted rights to its branding. Reuse is subject to the repository's rights notice.

## How to contribute

Participants can report unclear documentation, describe reproducible interface issues and propose features around actual tasks. A useful report includes the relevant page, the expected result and what happened. Private credentials and exploitable security details do not belong in a public report.

Creators contribute by publishing clear project information, maintaining their links and explaining their own commitments accurately. Community members contribute by asking specific questions, sharing constructive feedback and distinguishing verified information from speculation.

## Direction

SPAWN's intended contribution is a connected environment for turning ideas into public projects and maintaining the activity around them. Its development priorities combine creative tools, practical transaction flows and community participation, with clear boundaries between what the platform provides and what each creator is responsible for.
