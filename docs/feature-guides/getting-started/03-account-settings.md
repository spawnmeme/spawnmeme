# 03. Accounts, Settings and wallet linking

**Open:** [Settings](https://spawnmeme.com/settings). Use this when you want account-based project tools or need to attach wallet activity to your account.

## Create or access an account

1. Use **Create account** or **Sign in** and complete the options shown by the site.
2. Return to Settings. Confirm that the account is yours before importing projects.
3. In **Email profile**, edit **Full name** and choose **Save profile** if needed. The email field is read-only here.

Wallet-only deployment, My Wallet and several community tools do not require you to create an email account. The full AI project builder does.

## Link a Solana wallet

1. Sign in to the intended SPAWN account.
2. Under **Solana wallet**, choose **Connect wallet** and select the correct account in the wallet app.
3. Choose **Sign and link wallet**.
4. Read and sign the ownership message. This proves control; it does not transfer your assets.
5. Check the confirmation and open **My Spawns**. If a linked wallet still has unimported drafts, choose **Import wallet drafts**.

Linking is not a token transfer and does not replace a token's on-chain creator wallet. Continue using the original launch wallet for creator-only actions.

## Expected result

The wallet appears as linked to your account. Eligible wallet idea drafts are added to My Spawns. Account-based quests that need on-chain evidence can use a verified linked wallet where supported.

## Troubleshooting

| Problem                                    | Resolution                                                                                                                                          |
| ------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| No link button                             | Sign in, connect a wallet, and check whether it is already linked.                                                                                  |
| Message signing error                      | Use a compatible Solana signer; see [wallet setup](02-connect-wallet.md).                                                                    |
| Draft not visible                          | Verify the wallet that created the draft, choose **Import wallet drafts**, then reopen My Spawns.                                                   |
| A launched token is missing from My Spawns | Also check [Creator Dashboard](../launch-and-manage-tokens/11-creator-dashboard.md) with the launch wallet. Account projects and wallet launch records are different views. |
| Session expired                            | Sign in again to the same account and repeat the unfinished read or verification step. Check receipts first if a payment had already been sent.     |
| Email needs changing                       | This page does not provide an email-edit control. Ask through [official support](../reference-and-support/39-support-and-safety.md).                                      |

Linking and importing do not require an on-chain payment. Never pay someone who claims a transfer is needed to “verify” your wallet for Settings.
