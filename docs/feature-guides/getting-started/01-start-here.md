## A simple first session

1. Open the official site and choose a task from the table.
2. If the task needs a wallet, connect it and check the **full Solana address**. A connected Ethereum account is not a Solana account.
3. Read the form and fee quote. Prepare artwork and public links before starting a paid action.
4. Review the wallet prompt. A message proves ownership; a transaction can move assets or pay fees.
5. After sending a transaction, save its signature and wait for confirmation.
6. Check the expected result on the feature page and, where relevant, in the Explorer.

## Account and wallet are different

A SPAWN account stores full projects and provides account-based tools. A wallet holds on-chain assets and signs actions. Signing in to an account does not automatically select the wallet that launched a token. Connecting a wallet does not automatically import its drafts into your account. [Settings](03-account-settings.md) provides explicit wallet linking.

## What success looks like

You can identify which workflow you need, which identity owns the result, and whether the next approval is free verification or an on-chain action. Keep the same account, wallet and browser while completing a workflow.

## Costs and common questions

Browsing is free. Token launches, swaps, NFT creation, paid visibility and other on-chain actions can have separate costs. “Free deployment” refers to a particular platform fee waiver, not every network cost. See [Fees](../reference-and-support/37-fees.md).

**The site asks for an account when I only want to launch.** Open **Deploy a Token** directly instead of the full project builder.

**I do not see a tool described here.** Check [News & Updates](../platform-information/33-news-updates.md). Some controls depend on activation, wallet ownership or project access. This manual describes the app implementation reviewed on 9 October 2026; availability and quotes can change.
