# 18. Create an NFT collection

**Open:** [NFT collections](https://spawnmeme.com/nfts). A collection groups NFTs under an on-chain collection record. Creating a collection does not mint every artwork or create a public sale automatically.

## Before you start

Sign in to SPAWN, connect the wallet that should control the collection, and hold enough SOL for the quote and network costs. Prepare a collection name, description and cover image you have permission to use.

## Create the collection

1. Find **Create a collection**.
2. If offered, select your related SPAWN project and reuse its artwork, or upload your own cover.
3. Enter a name of 2–32 characters and a description of up to 1,000 characters.
4. Choose a royalty from 0% to 10%.
5. Review the connected creator wallet, exact fee and storage information.
6. Use the collection-creation action and wait while metadata is prepared.
7. Review and approve the wallet transaction, then keep the page open while it confirms.
8. Open the new collection page and save its address and public URL.

The collection uses Metaplex Core. Your wallet controls creator actions and is the royalty recipient. Royalties depend on marketplace support and enforcement; setting a percentage does not guarantee every resale pays it.

## Costs

The published base collection fee is 0.1 SOL. Eligible wallets holding at least 1,000,000 official $SPAWN can receive the displayed discount. Use the exact wallet-specific quote, and allow for permanent storage, Solana account/network costs and applicable protocol fees.

Collection details and uploaded permanent files cannot be edited or deleted through SPAWN after creation. Verify the artwork, wording and royalty before signing.

## Troubleshooting

| Problem                                    | Resolution                                                                                                                                       |
| ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| Creation form unavailable                  | Sign in and check feature activation. Public browsing alone is not creator access.                                                               |
| Invalid name or royalty                    | Use the displayed name limits and a numeric royalty from 0 to 10.                                                                                |
| Image rejected                             | Use the file formats and maximum size shown by the uploader; current NFT image upload supports PNG/JPG/WebP/GIF up to 5 MB.                      |
| Discount not applied                       | Verify the connected wallet and official token balance; refresh the quote before approving.                                                      |
| Transaction sent but collection not listed | Use the page's pending-transaction completion/check action and preserve the signature. Do not create a second collection to fix a listing delay. |
| Collection visible but no NFTs             | Mint an item or launch a public mint; the collection record itself is not an NFT inventory.                                                      |
