# 35. Launch Week and the free-deployment offer

**Open:** [Launch Week](https://spawnmeme.com/launch-week), or `/promo` in Telegram. Always check the live status before announcing or relying on a discount.

## October 2026 campaign

| Item          | Published campaign terms                                                          |
| ------------- | --------------------------------------------------------------------------------- |
| Starts        | 8 October 2026 at 15:35 UTC                                                       |
| Ends          | 15 October 2026 at 15:35 UTC                                                      |
| Waived        | The 0.025 SOL platform token-deployment fee                                       |
| Still applies | Solana network/account costs, any optional first buy, and unrelated paid services |

The page and bot are time-aware. This documentation preserves the campaign dates; it does not make the offer permanent or automatically extend it for seven days from whenever someone reads this page.

## Use the offer

1. Open Launch Week and check its active/upcoming/ended status and countdown.
2. Follow the deployment link to **Deploy a Token**.
3. Prepare the token and verify the correct wallet.
4. Check that the current platform-fee quote reflects the active offer.
5. Review the full wallet transaction, including costs that remain.
6. Approve and wait for confirmation and registration.

The fee waiver is applied automatically when eligible; do not send a separate payment to “activate” it. The server-issued launch quote and confirmation rules govern the actual charge. An old tab or screenshot does not reserve the promotional price.

## Troubleshooting

| Problem                                  | Resolution                                                                                                         |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| Wallet still asks for SOL                | Network/account creation and optional first-buy costs remain. Review the transaction breakdown.                    |
| Platform fee is no longer zero           | Check campaign end time, current server quote and whether the page is stale.                                       |
| Price changed during launch              | The app asks you to review the new fee and request deployment again; do not approve a price you have not reviewed. |
| Countdown differs from local expectation | Compare the stated UTC time with your timezone.                                                                    |
| Promo banner not visible                 | Open the dedicated Launch Week page and inspect current status.                                                    |
| Already paid but launch not registered   | Use [Retry registration](../launch-and-manage-tokens/09-deploy-token.md), not a second deployment.                                    |

This promotion concerns token deployment. It does not waive swaps, NFT fees, advertising, trending purchases or all Solana costs.
