# 34. Explore the interactive roadmap

**Open:** [The Hatching Plan](https://spawnmeme.com/roadmap), or `/roadmap` in Telegram. The mobile-friendly roadmap explains SPAWN's current toolkit and ideas under exploration.

## Navigate

1. Open the roadmap. With no specific chapter selected, it opens the final incubator chapter showing what is coming/exploring.
2. Use **The whole journey**, **Live tools** or **In the incubator** to filter chapters.
3. Select a chapter on the track, or use **Next chapter**.
4. Expand milestone rows to read their details.
5. Choose **Share this chapter** to share the selected stage.
6. Try the mystery egg interaction if you want the hatchling surprise; **Hatch again** resets that interaction.

On a phone, scroll the chapter controls if needed and tap a milestone to expand it. A shared URL can preselect a stage and filter, so it may open somewhere different from the default page.

## Understand status

**Live tools** describes available platform capabilities, although individual controls can still depend on activation, account access, wallet ownership or supported assets. **In the incubator / Exploring** describes direction being considered, not a delivery commitment. Scope and timing may change.

For precise steps, use the corresponding feature guide in this manual. For released changes, see [News & Updates](33-news-updates.md).

## Troubleshooting

| Symptom                        | Resolution                                                                                                      |
| ------------------------------ | --------------------------------------------------------------------------------------------------------------- |
| Page opens a different chapter | Check the shared URL's selected stage/filter; return to the base roadmap URL for the default.                   |
| Some chapters disappear        | Select **The whole journey**.                                                                                   |
| Cannot find a promised control | Check whether that item is Exploring rather than live, and whether the tool is enabled for you.                 |
| Share button cannot copy       | Copy the page URL after selecting the chapter.                                                                  |
| Animation is limited           | Device/browser accessibility or motion preferences can affect presentation; chapter text remains the reference. |

The roadmap is free to browse. The hatchling interaction is decorative, not a reward claim or wallet action.
