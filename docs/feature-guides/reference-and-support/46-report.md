# 46. Report a token, NFT collection or project

Flag something that looks like a scam, a copy or stolen work so the SPAWN team can review it.

**Open:** the token, NFT collection or project page, then press **Report**.

## Before you start

* Reports go to the SPAWN team for review.
* SPAWN can hide an item from the site and the Telegram bot. Nothing can be removed from Solana itself.
* For a security problem with the site, use [Responsible disclosure](49-responsible-disclosure.md) instead.

## Send a report

1. Open the page and press **Report**.
2. Choose what is wrong: scam or rug pull, pretending to be another project or person, stolen artwork or content, hateful or explicit content, illegal content, or something else.
3. Add details that help us check, such as links. Details are required if you chose **Something else**.
4. Optionally add an email or Telegram username so we can reach you.
5. Press **Send report**.

## Troubleshooting

| Symptom | What to do |
| --- | --- |
| "Choose a reason" | Pick one of the options first. |
| "Tell us briefly what is wrong" | Add a short description when you choose **Something else**. |
| "You have sent several reports recently" | Wait a while and try again. |
| You reported the same item twice | The second report is accepted but not counted again. |

**Success:** the form shows "Thanks. Your report was sent and will be reviewed."
