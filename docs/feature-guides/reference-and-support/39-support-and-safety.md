## Prepare a support report

Copy this and fill in only the relevant fields:

```
Feature and exact page URL:
What I expected:
What happened instead:
Exact error text:
Date/time and timezone:
Device and operating system:
Browser/wallet name and version:
Public wallet address (if needed):
Token mint / collection / project URL:
Order ID (if any):
Transaction signature (if any):
Was the transaction confirmed, failed, or still unknown?
Steps already tried:
Screenshot with private information removed:
```

A wallet address and transaction signature are public chain identifiers, but they can reveal activity associated with you. Share only what is needed through the appropriate official support context. Hide account emails, unrelated balances and private chat information in screenshots.

## Never share

* Seed phrase, recovery phrase or private key.
* Wallet backup file or password.
* Email/login verification code or session token.
* A signed transaction or approval you do not understand just because someone calls it a support step.

SPAWN support does not need your seed phrase to inspect a public transaction. Someone who contacts you privately after a public help request is not automatically an official representative. Navigate to the official channels yourself and verify whom you are speaking with.

## Before a paid or permanent action

Check the site domain, full mint/recipient and wallet account. Read the quote and wallet instructions. Burning, minting, sending assets and publishing permanent NFT files have consequences that a support conversation cannot simply undo. Use the appropriate guide's recovery action if submission already happened.

## What a good resolution looks like

You can match the support explanation to a visible status, confirmed chain receipt or verified account/project change. No support promise should require handing over wallet credentials or paying an unexplained “unlock” transfer.

## Content reports and private security reports

Use [Report](46-report.md) on a token, NFT collection or project for scams, impersonation, stolen content and other moderation concerns. SPAWN can hide hosted listings and bot visibility, but cannot erase Solana records.

Use [Responsible disclosure](49-responsible-disclosure.md) for security problems. Follow its testing rules and send reproduction details privately. **SPAWN does not run a paid bug bounty.**
