# 57. DEX Screener profiles and the DEX paid badge

**Open:** your launched token page with the creator wallet connected.

SPAWN can show a **DEX paid** badge from DEX Screener profile-order status. A paid profile is a marketing purchase, not a security review, token verification or endorsement.

## Creator steps

1. Look for **Get the DEX paid badge** on your token page. The ordering prompt is shown only to the connected creator.
2. Confirm that DEX Screener already lists the correct token. If SPAWN says it is not listed, check coverage before paying for a profile.
3. Choose **Copy token address**, then **Order on DEX Screener**.
4. On DEX Screener's own site, select Solana, check the full mint and supply the requested artwork, description and links.
5. Review DEX Screener's current price and terms before paying through that service.
6. Return to SPAWN. The card can show an order in review or a paid profile; approval and status refreshes may take time.

## Who handles the purchase?

DEX Screener sets the price, receives the payment and reviews the order. SPAWN does not collect a fee for this order and cannot approve it or refund it. Use the external service for order support.

## What visitors should understand

The badge reports a paid-profile status. It does not prove the creator is trustworthy or that the token is liquid. Missing or unknown data may hide the card; do not infer a failed order or an unsafe token from absence alone.

**Success:** the external order is approved and SPAWN shows the corresponding profile status after refreshing. Keep the order receipt if the two remain out of sync.
