# 31. Boost a token in the Spawn Feed

**Open:** the SPAWN token page → **Boost $TICKER**. Anyone with a supported wallet can buy a boost when the tool is enabled; creator ownership is not required.

## What a boost does

Boosts increase paid visibility in SPAWN's discovery/feed ordering. **Hot Spawns** includes actively boosted tokens, and boost counts influence **Fresh Spawns** ordering. A boost is not a token purchase, an organic Trending rank or a Telegram sponsored campaign.

## Buy a boost

1. Confirm the token's full mint on its page.
2. Read the current price per boost and duration.
3. Choose **1x**, **5x**, **10x** or **25x**.
4. Review **Boost for \[total] SOL**.
5. Connect the payer wallet if needed, then choose the action.
6. Review and approve the payment transaction, which includes the token-specific reference.
7. Wait for **Boosted** and the updated active count.
8. Open the feed to check the relevant category.

The screen currently uses 24 hours as the default duration, but the active price/duration are configurable. Read the displayed live values. Network fees are additional. Boost purchases are described as nonrefundable website visibility, not a guarantee of placement duration beyond the purchased terms or a particular number of impressions.

## Troubleshooting

| Problem                          | Resolution                                                                                                    |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| Button disabled                  | Wait for pricing/configuration and wallet connectivity.                                                       |
| Payment sent but count unchanged | Preserve the signature, wait and reload the same token page. Saved pending confirmation is checked on return. |
| Still missing after confirmation | Contact support with the token and signature before paying again.                                             |
| Boost count later fell           | Time-limited boosts expire. Check the purchase time and duration.                                             |
| Token not first on the feed      | Other tokens may have more active boosts, and official pinning/category rules can affect order.               |
| No Trending badge                | Boosts and [Trending promotion](30-trending.md) are separate features.                           |

**Success:** the payment is verified and the active boost count changes for the intended token. Save the receipt until that happens.
