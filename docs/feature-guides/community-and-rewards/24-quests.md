# 24. Quests, points and the leaderboard

**Open:** [SPAWN Quests](https://spawnmeme.com/quests). Participate with a wallet or account. On-chain tasks require verified wallet evidence; account users may need to link that wallet in Settings.

## Get started

1. Choose **Connect and sign wallet**, **Sign with wallet**, or the account option.
2. Read **Your Spawn Points**, **Quests complete** and **Check-in streak**.
3. Choose **Check in · +1 point** once each UTC day. Local midnight may differ from the UTC reset.
4. Read the current streak rule and bonus shown on the page.

## Complete tasks

1. Pick a quest and follow its action link.
2. Complete the action using the intended account/wallet.
3. Return to Quests and choose **Claim** when offered.
4. Confirm the task changes to **Done** and the points/activity update.

Tasks include saving a draft, a first trade, launching, boosting, burning, referring and community participation. Each listed quest pays once; trading more does not keep awarding trade points. A burn quest uses the burn record from that device, so return from the same browser used for the burn.

For Telegram, use **Verify in Telegram**, complete the bot's membership check and return to **Check again**. For X, the interface opens the official account and offers **Claim**; the page explicitly describes follows as a trust-based task, not independently verified following.

## Invite a friend

Copy the dedicated **Invite a friend to Quests** link. The current qualification rule requires a new member to use it, verify a wallet and check in on two UTC days at least 20 hours apart. Clicks and signups alone do not qualify. Check **qualified** and **pending** counts.

This points invitation differs from the SOL-earning [Refer & Earn](25-referrals.md) program. Use the appropriate link for your goal.

## Troubleshooting

| Problem                              | Resolution                                                                               |
| ------------------------------------ | ---------------------------------------------------------------------------------------- |
| Wallet task will not claim           | Verify the correct wallet; account users should check Settings linking.                  |
| Check-in still says today            | Check UTC day boundaries.                                                                |
| Activity not recognized yet          | Allow indexing time, then retry the claim.                                               |
| Burn quest missing on another device | Use the browser that recorded the burn. Do not burn again solely to troubleshoot points. |
| Telegram task pending                | Complete the bot flow and use **Check again**.                                           |
| Referral pending                     | Confirm both qualifying check-ins and wallet verification occurred.                      |
| Points absent from leaderboard       | The board shows the top 20 and updates periodically; it is not a full participant list.  |

Points have no cash value or guaranteed token/airdrop conversion. Some optional tasks incur their normal action costs. You can participate in free tasks without making purchases just to accumulate points.
