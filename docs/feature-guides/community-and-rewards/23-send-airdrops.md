# 23. Send a creator airdrop

**Open:** [Send an airdrop](https://spawnmeme.com/airdrop/send). Only the wallet that launched a supported SPAWN token can distribute it through this tool.

## Before you start

Connect the original creator wallet. It must hold the tokens you intend to give away and enough SOL for the platform quote, transfer fees and any recipient token-account creation. A creator wallet does not automatically hold the full launch supply.

## Review and draw recipients

1. Select your token.
2. Enter **Tokens for each wallet** and **How many wallets**.
3. Review the total tokens, per-recipient SPAWN fee, estimated network/account costs and number of approvals.
4. Choose **Review airdrop**.
5. Check the quoted recipient count. The available list can be smaller than requested, including when wallets already received that token from you.
6. Choose **Pay \[amount] SOL and draw wallets**, or **Draw wallets** if the current quote has no platform charge.
7. Approve any required payment. After confirmation, inspect the randomly selected recipients.

The fee is not refunded merely because you decide not to send after drawing recipients. The live review shows the applicable terms and amount.

## Send the tokens

1. Choose **Send to \[number] wallets**.
2. Review each batch in your wallet. The page displays how many approvals are needed.
3. Keep the page open while batches confirm.
4. Monitor the sent count and **Wallets drawn** list.
5. When complete, confirm **Every wallet has received its tokens** and inspect the transaction links.

You can stop between batches and resume later. A completed batch remains sent; resuming is for the remaining recipients, not an instruction to repeat the entire distribution.

## Recovery and troubleshooting

| Situation                               | Correct action                                                                               |
| --------------------------------------- | -------------------------------------------------------------------------------------------- |
| Fee paid but recipients not drawn       | Use **Draw my wallets** on the saved payment receipt.                                        |
| Partial distribution                    | Use **Continue sending**, or **Your airdrops** → **Continue**.                               |
| History not visible                     | Choose **Sign with your wallet to see past airdrops**.                                       |
| Last batch still confirming             | Wait, inspect the signature and use Continue afterward; do not create a replacement airdrop. |
| Not enough tokens for remaining wallets | Add the needed tokens to the same creator wallet, then continue.                             |
| Not enough SOL                          | Allow for opening token accounts for recipients, not just the platform fee.                  |
| No eligible tokens listed               | Check the original creator wallet and completed SPAWN launch registration.                   |
| Fewer recipients than requested         | Use the reviewed available count; do not assume the larger number was paid for or drawn.     |

**Success:** the recorded sent count matches the selected recipient count, supported by confirmed batch receipts. Recipients do not claim or pay to receive the tokens.

## Per-recipient fee

The SPAWN airdrop fee is **0.001 SOL per recipient**. The distributed tokens, Solana transaction fees and any recipient account creation costs are separate. Review the batch quote before signing.
