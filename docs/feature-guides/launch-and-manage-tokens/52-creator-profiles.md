# 52. Explore a creator profile

**Open:** [Leaderboard → Creators](https://spawnmeme.com/leaderboard?tab=creators), then choose **Creator page**. Each profile has a shareable `/creator/<wallet>` address.

Profiles bring together a wallet's SPAWN launches and recorded activity. You can read them without connecting a wallet. Connecting the same wallet adds a **You** label; it does not let the creator rewrite the activity record.

## Read a profile

1. Check the full wallet address and use **Solscan** to inspect it independently.
2. Review **Launches**, **Graduated**, **Traded by others** and **With locked tokens**.
3. Compare the creator's own recorded buys and sells with activity from other wallets.
4. Open each launch to inspect its mint, token page and linked project page. The list includes launch dates, other traders, SOL in the curve and available lock information.
5. Check the next unlock date and the proportion locked by the creator. A locked portion does not cover unlocked holdings.
6. Use **Copy page link** to share the profile.

## Understand the scope

The page summarizes recorded activity for tokens listed on SPAWN. Creator buy/sell totals cover recorded curve trades. Transfers and activity through other wallets can change holdings without appearing as a sale by this wallet. One person can control multiple wallets.

The figures refresh every few minutes. A successful previous launch, badge or graduation is not an endorsement or a prediction for the next launch.

## Troubleshooting

An invalid address produces an address error. **No SPAWN launches from this wallet** can mean the wallet has not launched here or its launches were retired. If the profile cannot load, refresh later rather than assuming its activity is zero.

**Success:** you can compare the creator's launches, recorded trading and lock information using the same public wallet address.
