# 06. Spawn Studio: build and publish your page

**Open:** your project checklist → **Write your page** → **Open my page**. You need the owning SPAWN account.

## Edit the page

1. Tap or click a section in the page canvas to select it.
2. Edit its available content fields. On a phone, the editing panel opens from the bottom; choose **Done** to return to the page.
3. Choose **Add a section** to add a supported section and complete its content.
4. Use **Move up**, **Move down**, **Copy** or **Remove** to organize the selected section. Confirm removal only when intended.
5. Watch the status at the top. Wait for **Saved** before leaving.

Sections may include text, images, roadmap, tokenomics, FAQs and other blocks offered in the editor. Availability can depend on project access. A decorative or informational block does not by itself establish an external service connection.

## Search appearance and theme

Open **More options** → **How your page looks on Google** to edit search metadata. Where the project has access, **Colors and fonts** opens theme controls. Search metadata influences the information your page supplies; it does not guarantee ranking or immediate search-engine updates.

## Preview and publish

1. Choose **Preview** and inspect the page on both a narrow phone layout and a wider screen.
2. Check button destinations, social links, image cropping, spelling and token addresses.
3. Return to the builder and choose **Publish**, or use **Put your page online** from the project checklist.
4. Use **Look at it first** if you want one final preview.
5. Choose **Publish my page**.
6. Use **Copy link** or **Open my page**. The public address has the form `https://spawnmeme.com/p/your-page-slug`.

After publication, saved edits appear on the public page. Do not assume later edits remain private drafts. Review wording before applying changes to a published page.

## Costs and availability

Spawn Page publishing has no site deployment fee. Token deployment is a separate optional action with its own quote. **Custom domains are not available in the current publishing flow**; the page explicitly says that using your own web address is not available yet.

## Troubleshooting

| Problem                               | Resolution                                                                                                          |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| **Not saved**                         | Keep the editor open, copy important unsaved text somewhere safe, restore connectivity and choose **Try again**.    |
| Changes missing publicly              | Wait for **Saved**, verify the correct project URL, then refresh the public page.                                   |
| Page still private                    | Complete **Publish my page** and check for a public link. Preview alone does not publish.                           |
| Section removed accidentally          | If no undo control is offered, add the section again and restore its content. Keep a copy before destructive edits. |
| Colors/fonts or analytics unavailable | These controls are access-dependent; see [analytics and access](07-analytics-and-access.md).                       |
| Page not found                        | Reopen from My Spawns under the owning account, and verify the complete public slug.                                |

**Success:** the public link opens your intended page, including the latest saved content, without requiring the visitor to sign in.

## Find and share your published project

Published pages appear in [Projects](47-projects.md) within about a minute. Publishing a page does not launch a token. The public page footer includes **Share** for a page-specific preview and **Report** for content concerns. See [sharing](../platform-information/45-share-links.md) and [reporting](../reference-and-support/46-report.md).
