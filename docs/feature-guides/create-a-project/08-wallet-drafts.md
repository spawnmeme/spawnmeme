# 08. Save ideas with wallet-only drafts

**Open:** [Wallet drafts](https://spawnmeme.com/wallet-create). This tool saves project ideas against a verified wallet. It is separate from the saved token-launch drafts on **Deploy a Token**.

## Save an idea

1. Choose **Connect wallet**.
2. Choose **Sign to manage wallet drafts** and approve the free ownership message.
3. Enter the project name, ticker, idea brief and optional tagline.
4. Choose **Spawn draft** for a new idea or **Save draft** while editing.
5. Check **Your wallet drafts** and use **Edit draft** to resume it.

The idea brief must contain meaningful text; the form accepts 10–2,000 characters. Wallet draft names and tickers may allow more characters than a launch. Before launching, use the stricter token limits of 1–32 name characters and 2–10 uppercase letters or numbers for the ticker.

## Move into the full builder

1. Sign in or create a SPAWN account when you want the full AI and page-building tools.
2. In [Settings](../getting-started/03-account-settings.md), connect the same wallet and choose **Sign and link wallet**.
3. If needed, choose **Import wallet drafts**.
4. Open the imported project in My Spawns, or use **Open in builder** when shown on the claimed draft.

You can instead launch a token directly with no email through [Deploy a Token](../launch-and-manage-tokens/09-deploy-token.md). Importing an idea draft is not a prerequisite for that separate workflow.

## Result and costs

A saved wallet draft is an idea record, not an on-chain token or a published website. Ownership verification and saving the draft do not send a Solana transaction.

## Troubleshooting

| Problem                                         | What to do                                                                                                 |
| ----------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| Draft list is empty                             | Connect the original wallet, then sign to load its drafts.                                                 |
| Session expired                                 | Repeat wallet verification in the current browser tab.                                                     |
| Cannot access AI or builder from a wallet draft | Create/sign in to an account and link the wallet for those tools.                                          |
| Draft already claimed                           | Open it through the owning account's My Spawns.                                                            |
| Launch draft not listed here                    | Open **Deploy a Token** → **Verify wallet / load my launches**; the two draft tools serve different tasks. |
| Invalid idea/name/ticker                        | Follow the field limits, remove unsupported ticker characters and save again.                              |
