# 47. Browse published projects

See every project page creators have published on SPAWN.

**Open:** [Projects](https://spawnmeme.com/projects). It is also in the **Tools** menu and the footer.

## What the page shows

Published projects, newest first. Each card has the project's logo, name, ticker and tagline, with:

* **View project:** opens the creator's project page.
* **Token page:** opens the token, when the project has launched one. Otherwise the card says **No token yet**.

A project page is the creator's own content and is not an endorsement by SPAWN.

## Get your project listed

1. Create a project and open it from **My Spawns**.
2. Choose **Publish page**.
3. Your project appears on the Projects page within about a minute.

Publishing a page does not launch a token. A project whose token has been hidden by SPAWN is not listed.

## Troubleshooting

| Symptom | What to do |
| --- | --- |
| Your project is missing | Check it is published, then reload the Projects page after a minute. |
| "Projects could not be loaded" | Refresh the page. |
| The card has initials instead of a logo | The project has no logo yet. Add one in the image studio and publish again. |

**Success:** your project card appears and **View project** opens your page.
