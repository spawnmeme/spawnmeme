# 04. SPAWN AI: create a project

**Open:** [Spawn a Project](https://spawnmeme.com/create). This is the full account-based creation flow. If you already have your token name and artwork, [direct deployment](../launch-and-manage-tokens/09-deploy-token.md) is a separate, shorter flow.

## Before you start

Sign in to SPAWN. Prepare an idea of at least ten characters: what the project is, its character or theme, its intended audience and the tone you want. Avoid private information in creative prompts.

## Create your project

1. Describe the project idea. A useful example is: “A playful space frog community with a cobalt-and-lime mascot and friendly, short copy.”
2. Choose **Suggest a name for me** if you want AI help.
3. Review the suggested name, ticker, tagline, description, mascot direction and social ideas. Choose **Suggest again** if you want another concept.
4. Edit **Project name**, **Short code (ticker)** and optional **Tagline**. AI suggestions are starting points; check spelling and any claims yourself.
5. If you want a richer starting layout, use **Start with more sections on the page** and choose a template.
6. Save/create the project using the form's primary action.
7. On the project checklist, work through **Pick an image**, **Write your page**, and **Put your page online**. **Launch your token** is optional.

You can enter project details manually if AI is unavailable. A page can exist without a token, and creating a concept does not deploy a token or publish a social post.

## Naming limits

The idea generator and project fields can allow different lengths from the token launch form. A token launch requires a name of 1–32 characters and a ticker of 2–10 uppercase letters or numbers. Choose launch-compatible values now if you plan to launch later.

## What is saved

The account project stores its identity and generated concept. The next screen shows the project checklist and ideas for getting the word out. Social starters remain drafts until you publish them yourself.

## Troubleshooting

| Problem                                   | What to do                                                                                                                                              |
| ----------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Idea rejected                             | Add a meaningful description of at least ten characters.                                                                                                |
| AI request fails                          | Keep your idea, try again later, or fill in the project fields manually.                                                                                |
| Sign-in requested                         | Full AI generation and saving an account project require authentication. Use [wallet drafts](08-wallet-drafts.md) for a wallet-only idea draft. |
| Project opens with no image               | This is expected; choose artwork in the next step.                                                                                                      |
| Project not found                         | Open it from My Spawns while signed in to its owning account.                                                                                           |
| Project title will not fit the token form | Shorten it before the launch draft is locked, or create the correct token draft separately.                                                             |

Creating an idea and publishing a Spawn Page are distinct from paid token deployment. Paid Spawn Kit artwork upgrades are not currently offered.
