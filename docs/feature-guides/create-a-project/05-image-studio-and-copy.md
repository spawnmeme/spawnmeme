# 05. Image Studio, Spawn Kit and social starters

**Open:** your project in **My Spawns**, then **Pick an image** or the **Project image studio** section. Sign in as the project owner.

## Upload your own artwork

1. Choose **Upload PNG, JPG or WebP**.
2. Select an image under 5 MB. Square artwork works best for the project avatar and future token launch.
3. Wait for the selected-image preview and saved confirmation.
4. Open the page preview to check framing and readability.

Uploading your own image is free. This upload control is different from Telegram Buy Bot media: it does not accept MP4 or GIF.

## Generate artwork

1. Choose **Mascot icon**, **Sticker art** or **Project scene**.
2. Optionally enter up to 180 characters of creative direction.
3. Choose **Generate an image option** and wait for the result.
4. Review the image. Choose **Use this image** to make it the selected artwork.

The studio provides one free AI option. Read the remaining count; generating an image does not automatically select it. Paid Spawn Kit upgrades are not currently offered.

## Extra image options

The screen may still say "two more require an available Spawn Kit upgrade". That is outdated wording: there is no paid Spawn Kit offer. Use an available variant or upload your own artwork.

## Polish project copy

1. In **Spawn AI · polish the project**, choose **Draft project copy**.
2. Review and edit the short tagline, page headline, page introduction, search title, search description and three social starters.
3. Choose **Apply reviewed copy**.
4. Open **Preview page** and confirm the result.

The page shows the remaining allowance out of five included copy drafts. Manual editing stays available. Applying copy updates the project fields and existing hero section; if you removed the hero, add or edit the relevant section in the builder. Social starters are saved suggestions, not automatically posted announcements.

## Troubleshooting and limits

| Symptom                                   | Resolution                                                                                                  |
| ----------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| Image upload rejected                     | Use PNG/JPG/WebP under 5 MB; check the actual file type, not only its extension.                            |
| AI options exhausted                      | Use an existing variant or upload your own artwork.                                                         |
| Generated art does not appear on the page | Choose **Use this image**, then refresh the preview/public page.                                            |
| AI copy will not apply                    | Add a nonempty headline and introduction; confirm your session and ownership.                               |
| Token still shows its old art             | Launched token metadata is separate and locked. Project image changes do not rewrite an existing token.     |

For a consistent brand, reuse the approved logo and selected character image across your page and manually published social posts. [Buy Bot media](../telegram-and-promotion/29-buybot-customization.md) can be changed independently.
