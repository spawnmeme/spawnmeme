# 14. Markets, charts and watchlists

**Open:** [SPAWN Markets](https://spawnmeme.com/markets). This directory includes tokens beyond SPAWN launches. A market listing is not a SPAWN launch record or endorsement.

## Find a market

1. Choose **Trending**, **Top Volume**, **Gainers**, **Losers**, **New Pools** or **Watchlist**.
2. Select a ranking period: **5m**, **1h**, **6h** or **24h**.
3. Search by name, ticker or full mint. Use the mint to distinguish similarly named tokens.
4. Read price, change, volume, liquidity and available market cap.
5. Use **Refresh** to request updated results.

Typing a search changes the results to a search view. Selecting a category clears that search. **New Pools** means recently indexed first liquidity pools within provider coverage, not every newly deployed Solana token.

## Save a watchlist

Choose the star next to a token. Open **Watchlist** to see saved entries; choose the star again to remove one. The watchlist is stored on the current device/browser. It does not automatically follow your email account or wallet to another device, and clearing site data can remove it.

## Research a token page

1. Open **View token & trade** or the token name.
2. Compare the full mint, then use **Copy** or **Solscan** as needed.
3. Read price, 24-hour change, liquidity and market cap.
4. Inspect the embedded chart or choose **Open chart on DEX Screener** when available.
5. Use the embedded [Spawn Swap](15-spawn-swap.md) panel if an executable route exists.

The chart represents an indexed pool; a swap can route through a different pool. A provider's “verified” label is a data label, not a guarantee of safety, liquidity or future performance.

## Troubleshooting

| Symptom                           | Resolution                                                                                                             |
| --------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| No result by ticker               | Search the full mint; the provider may not index the token yet.                                                        |
| Empty Watchlist on another device | Re-add tokens there; storage is local.                                                                                 |
| Chart unavailable                 | Use the linked external chart if offered, or wait for indexing. A missing chart does not establish that trading works. |
| Previously loaded data warning    | The refresh failed; treat the displayed figures as older data.                                                         |
| Token listed but no swap route    | Listing and route availability are separate. See [swap recovery](15-spawn-swap.md).                         |
| Mobile table looks different      | Phone layouts show cards with the same main discovery actions.                                                         |

Browsing and watchlisting have no platform fee. Actual swaps carry their quoted costs.
