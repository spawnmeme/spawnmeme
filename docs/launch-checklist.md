# Creator launch checklist

Use this checklist for your own project. It is a preparation guide, not a requirement to complete every optional SPAWN feature.

[Start a project](https://spawnmeme.com/start) · [Deploy a token](https://spawnmeme.com/create-token)

## 1. Shape the identity

- [ ] Choose a name, symbol and clear project description.
- [ ] Review the artwork at both full size and small avatar size.
- [ ] Check that you have permission to use the name and artwork.
- [ ] Review AI-generated text and images before publishing them.
- [ ] Decide which public website, X account and Telegram group represent the project.

## 2. Prepare the public page

- [ ] Add the project description and official community links.
- [ ] Preview the page on desktop and a phone.
- [ ] Check spelling, image crops and link destinations.
- [ ] Explain what is available today and what is still planned.
- [ ] If using an optional website, check its content separately before sharing it.

## 3. Review the launch

- [ ] Connect the intended creator wallet on the intended network.
- [ ] Review the token details, launch configuration and current costs shown by the app.
- [ ] Keep enough SOL for the transaction and network costs.
- [ ] Read the wallet approval before signing.
- [ ] Wait for confirmation and verify the resulting mint and transaction on the explorer.
- [ ] Save the confirmed project URL and full mint address.

If a transaction appears pending, check its status before attempting the same action again. Use the app's recovery instructions or [Help](https://spawnmeme.com/help).

## 4. Open the community

- [ ] Pin a welcome message containing the confirmed project URL and full mint.
- [ ] Add clear rules and identify your administrators.
- [ ] Add [@spawnmeme_bot](https://t.me/spawnmeme_bot) if the token meets current [Buy Bot coverage](buy-bot-and-trending.md).
- [ ] Connect the token from a visible group-admin account and set the desired minimum alert amount.
- [ ] Check that `/ca` and `/buy` point to the expected token in your project group.
- [ ] Explain organic rankings and paid promotions accurately if using Trending.

## 5. Keep it current

- [ ] Check the [creator dashboard](https://spawnmeme.com/creator-dashboard) with the launch wallet.
- [ ] Review public links and pinned information after changes.
- [ ] Respond to community questions and document known limitations.
- [ ] Publish updates about completed work and distinguish future ideas from commitments.

## Copyable project handoff

Fill this in privately, then share only the public information your team needs:

```text
Project name:
Token symbol:
Confirmed mint:
Project page:
Explorer link:
Website:
X:
Telegram:
Public support channel:
Launch transaction:
Buy Bot status:
Next community update:
```

Never put a seed phrase, private key, bot token or account recovery code in this handoff.
