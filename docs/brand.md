# SPAWN brand and media

## Name

**SPAWN** is the platform name. Use **SpawnMeme.com** when referring to its website.

## Tagline

**Spawn it. Launch it. Send it.**

## Short description

SPAWN brings project creation, branding, Solana token launches, trading, NFTs and community tools into one connected platform.

## Extended description

SPAWN helps creators turn an idea into a project with its own identity, artwork and public presence. Creators can launch Solana tokens, create NFT collections and connect community tools. Markets, Spawn Swap, wallet tools and on-chain exploration bring discovery and interaction into the same platform.

## Visual identity

The lime hatchling, dark laboratory imagery and SPAWN wordmark form the recognizable visual identity. The repository's assets use the established lime, charcoal and white palette.
