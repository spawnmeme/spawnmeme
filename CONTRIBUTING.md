# Contributing to SPAWN's public documentation

We welcome clear documentation corrections, reproducible interface reports and thoughtful feature ideas.

## Choose a contribution

- **Documentation:** name the page, explain the problem and suggest accurate wording.
- **Feature idea:** describe the user, task and practical benefit.
- **Interface issue:** provide the page URL, browser, device, expected result and reproduction steps.

Use [the issue templates](https://github.com/spawnmeme/spawnmeme/issues/new/choose). For account-specific help, use [SPAWN Help](https://spawnmeme.com/help).

## Documentation pull requests

Keep changes focused. Match the existing terminology, preserve official links and distinguish available tools from ideas under exploration. Include a short explanation of the problem your edit solves.

Only contribute material you have the right to submit. Do not add private application code, credentials or third-party artwork without permission. A contribution does not change this repository's rights notice.

## Public reports

Remove personal details, private wallet information, authentication tokens and confidential screenshots. Never include seed phrases, private keys, RPC keys or bot tokens.

Report security concerns through the process in [SECURITY.md](SECURITY.md), not an ordinary public issue.

Keep discussion constructive. Spam, impersonation and unrelated promotional content may be removed.
